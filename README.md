## 🌟 Overview

**RajBike** ek modern, dynamic, aur fully responsive motorcycle web platform hai jo users ko India ke top motorcycle brands (Royal Enfield, KTM, Bajaj, Hero, TVS, Yamaha) ki full specification dekhne, live search & filter karne, interactive **EMI Calculation** karne, aur online **Test Ride Pass** book karke print karne ki suvidha deta hai.

Designed with a sleek **Dark Metallic Theme** with glowing `#FF5500` orange accents, Orbitron typography, smooth glassmorphism modals, aur full mobile responsiveness!

## ✨ Key Features

- **🏍️ Detailed Motorcycle Fleet:**
  - High-definition image previews and complete technical specifications (Engine CC, Power, Mileage, Kerb Weight, Ex-showroom Price).
  - One-click detailed spec modal popup.

- **🔍 Smart Filter & Instant Search Engine:**
  - Filter by major brands (*Royal Enfield, KTM, Bajaj, Hero, TVS, Yamaha*).
  - Real-time search bar + Price/Mileage sorting options (*Low to High, High to Low, Best Mileage*).

- **🧮 Interactive EMI Finance Calculator:**
  - Dynamic monthly loan installment (EMI) estimation with real-time sliders for Down Payment, Loan Tenure, and Interest Rates.
  - Automatic safeguards preventing invalid or negative principal calculations.

- **📝 Instant Test Ride Booking & Official Pass Slip Generator:**
  - Seamless form validation for booking test ride slots.
  - Generates an official, printable **Test Ride Pass Slip** with unique Pass ID, date stamp, and customer details with built-in PDF/Print stylesheet support.

- **📱 Fully Responsive & Accessible:**
  - Mobile drawer menu, keyboard ESC navigation for modals, auto-clamped date limits, and sleek slide-in toast notifications.
